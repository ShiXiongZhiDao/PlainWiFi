## ✨ 功能特性

- **📋 WiFi 配置一览**：列出当前 Windows 账户已保存的所有无线网络（自动去重，兼容多无线网卡/移动热点场景）
- **🔍 即时搜索**：按名称过滤，长名称自动省略号 + 悬停显示全名
- **👁 密码显隐**：默认掩码显示，双击名称卡一键复制 `名称 + 密码` 到剪贴板
- **📱 分享二维码**：按标准 `WIFI:` 载荷生成二维码（正确转义特殊字符，支持 WPA/WPA2/WPA3、WEP、开放网络与隐藏网络），手机扫码免密连 WiFi；支持复制图片与保存 PNG
- **📦 一键备份导出**：将本机全部已保存 WiFi（名称/密码/加密类型/是否隐藏）导出为带 BOM 的 CSV，Excel 直接打开不乱码；文件纯本地生成，不经过任何网络
- **🌓 深色 / 浅色主题**：设置页可视化切换，偏好自动保存；「跟随系统」选项实时跟随系统外观
- **🌐 中 / 英双语**：跟随系统语言自动选择，设置页随时切换
- **🔄 托盘常驻**：关闭窗口后驻留系统托盘，右键菜单快速刷新/唤回
- **🚀 应用内升级**：启动后台检查新版本，发现更新弹窗展示版本号与更新内容，由你选择立即更新 / 跳过此版本 / 稍后再说；更新包经 minisign 签名校验防篡改，安装完成后一键重启生效

## 🔒 隐私与安全

我们理解这款工具处理的是敏感信息，因此承诺：

| 承诺 | 说明 |
|------|------|
| **100% 本地运行** | 密码通过 Windows 自带命令 `netsh wlan` 读取，与你在「设置 → WLAN → 已知网络 → 显示字符」看到的内容完全一致 |
| **零数据上传** | 应用没有任何服务器，不收集、不上传任何数据；联网仅用于升级：启动时检查一次更新清单、下载经签名的更新包，全程无数据外发 |
| **零磁盘落盘** | WiFi 密码只存在于应用内存中；除你主动导出的备份文件/二维码图片外，本地仅保存界面偏好（主题/语言/侧栏宽度） |
| **无需管理员** | 只能读取当前登录用户自己有权查看的配置，不会尝试提权 |
| **开源可审计** | 全部代码公开，欢迎审查与安全建议 |

> ⚠️ 部分杀毒软件可能对"读取 WiFi 凭据"类工具报警，这是此类工具的共性（如 NirSoft WirelessKeyView 同样如此）。源码公开可自证清白，也欢迎提交误报申诉。

## 🚀 快速上手

1. 启动应用，自动加载本机已保存的 WiFi 列表
2. 点击左侧列表选择网络 → 右侧显示名称、密码（点击 👁 明文切换）与分享二维码
3. 手机相机对准二维码 → 自动弹出"加入网络"
4. 左下角 ⚙ 打开设置：主题 / 语言 / 备份 / 升级 / 关于

## ❓ FAQ

**Q：为什么列表里没有某个连过的 WiFi？**
A：应用只显示当前用户账户可见的配置文件。以管理员或其他用户身份连接保存的网络不在其中。

**Q：能看公司 / 校园（802.1X 认证）网络的密码吗？**
A：不能。企业网络的凭据由账户系统管理，不存储在本地 WiFi 配置文件中，这是 Windows 的安全机制。

**Q：二维码手机扫了没反应？**
A：请确认扫码工具支持 `WIFI:` 载荷（iOS 相机、微信、支付宝及主流安卓浏览器均原生支持）；隐藏网络生成的码已带 `H:true` 标记。

**Q：数据存到哪里了？**
A：哪里都没有。关闭应用即全部消失，本地仅记录界面偏好。
